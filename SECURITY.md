# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues, discussions, or pull requests.

Use the repository's private vulnerability-reporting flow when it is available. Otherwise, contact the maintainers privately through the SiriusSoftwareLtd GitHub organization profile. Include a clear description, affected endpoint or component, reproduction steps, and potential impact. Do not include credentials or production data.

Maintainers will acknowledge a valid report, investigate it, and coordinate a fix and disclosure timeline where appropriate.

## Scope

Security reports for the Worker source, its request handling, cache behavior, and deployment configuration are in scope. Reports about third-party services should also be reported to the relevant provider.
